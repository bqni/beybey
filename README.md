# Beybey · Arène Beyblade

Appli web de fan pour **Beyblade X** : collection de toupies, calculateur de build, matchs 3v3 avec historique.

**▶ https://bqni.github.io/beybey/**

*🇬🇧 Fan-made web app for Beyblade X: collection, build calculator, matches. Open the link, works on phone and desktop. The app is available in **French and English** (Options > Langue / Language).*

## Bêta, à savoir

- Fait avec l'IA : des bugs sont possibles.
- Stats du dos des boîtes, poids approximatifs.
- Tout est stocké **en local** sur ton appareil. **Sauvegarde régulièrement** : *Options > Exporter* (toupies, photos, historique), *Options > Importer* pour restaurer.

## Installer sur téléphone

- **iPhone** : Safari > Partager > Sur l'écran d'accueil
- **Android** : Chrome > menu > Installer l'application

## Modifier ou héberger

Les toupies de base sont dans `data.js`. Le catalogue (environ 390 toupies Hasbro et Takara Tomy) est dans `catalogue.js`. Pour héberger ta version : GitHub *Settings > Pages* > branche `main`. Détails dans `LISEZ-MOI.txt`.
