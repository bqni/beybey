# Beybey · Arène Beyblade

Appli web de fan pour **Beyblade X** : collection de toupies, calculateur de build, matchs 3v3 avec historique.

**Volontairement minimaliste : tu ouvres, tu rentres tes toupies, tu joues, c'est tout.** Pas de compte, pas de shop, pas de news, pas de pub.

**▶ https://bqni.github.io/beybey/**

*🇬🇧 Fan-made web app for Beyblade X: collection, build calculator, matches. Deliberately minimal: open it, add your beys, play, that's it. No account, no shop, no news, no ads. Works on phone and desktop. The app is available in **French and English** (Options > Langue / Language).*

## Bêta, à savoir

- Fait avec l'IA : des bugs sont possibles.
- Stats du dos des boîtes, poids approximatifs.
- Tout est stocké **en local** sur ton appareil. **Sauvegarde régulièrement** : *Options > Exporter* (toupies, photos, historique), *Options > Importer* pour restaurer.

## Installer sur téléphone

- **iPhone** : Safari > Partager > Sur l'écran d'accueil
- **Android** : Chrome > menu > Installer l'application

## Modifier ou héberger

L'appli démarre sans aucune toupie : chacun ajoute les siennes (à la main ou depuis le catalogue). `data.js` est vide et facultatif. Le catalogue (environ 390 toupies Hasbro et Takara Tomy) est dans `catalogue.js`. Pour héberger ta version : GitHub *Settings > Pages* > branche `main`. Détails dans `LISEZ-MOI.txt`.
